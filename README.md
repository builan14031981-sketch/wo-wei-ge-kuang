# 我为歌狂 An1.0

聚合全网音源的 Windows 音乐下载器，一键将歌曲下载为 **MP3 320Kbps (CBR)** 并写入 ID3v2 元数据标签。

## ✨ 功能特性

- **多源聚合与自动容错**：整合 Meting 节点与 GDStudio 双引擎，启动自动探测音源状态，支持故障无感降级容错。
- **歌单直读与文本导入**：
  - **链接直读**：支持网易云、酷狗音乐（直读提取 100 首）、汽水音乐（直读提取 158 首）分享链接直接解析整张歌单。
  - **文本导入**：支持直接粘贴歌词/歌单文本（每行一首“歌手 - 歌名”）批量解析搜索导入。
- **历史记录持久化**：提供【🕘 历史搜索】与【🕘 历史解析】记录卡片，支持自动本地持久化（`history.json`）、一键快捷填充复用与清空。
- **后台静默无痕转码**：批量下载与转码全程后台静默处理，彻底消除弹框命令行黑框干扰。
- **批量并发下载**：多线程并行（默认 12 线程，可在设置中调整 4~16），支持真正可打断/停止下载、码率可选（320Kbps / 192Kbps）。
- **下载管理**：进度可视化、定位文件所在位置、试听、从列表移除及彻底删除本地 MP3 文件。
- **macOS 风格 UI**：浅色极简界面（PyQt6 + QSS），优化右键菜单与无边框交互体验。

## 📦 下载与安装

### 方式一：便携版（推荐）
解压 `我为歌狂便携版.zip`，双击 `WoWeiGeKuang.exe` 即可运行，**无需安装、免 ffmpeg**（ffmpeg 已内嵌）。

### 方式二：安装版
运行 `我为歌狂安装版.exe`，按向导安装，开始菜单/桌面生成快捷方式。
> 安装版由仓库内 `build/installer.nsi` 经 NSIS 编译生成。

## 🚀 使用说明

1. **单曲搜索**：选择音源（或全局聚合）→ 输入「歌名 歌手」→ 搜索 → 勾选 → 批量下载 / 单首下载。
2. **歌单解析**：
   - 粘贴酷狗、网易云、汽水音乐**公开**歌单链接 → 点击「解析歌单」→ 一键下载。
   - 或在「粘贴歌单文本」框直接输入多行歌曲名称 → 点击「解析文本歌单」导入。
3. **历史记录**：在搜索页或解析页下方可通过「🕘 历史记录」卡片快捷加载历史搜索词或歌单文本。
4. **下载管理**：在「下载管理」页查看进度、停止任务、定位目录、试听播放或彻底删除文件。
5. **设置**：修改输出目录、码率、并发线程数（即时生效）。

## ⚠️ 已知限制

- **网易云「我的」/私有歌单需要登录**，当前版本无登录功能，无法解析。请将歌单设为**公开**后使用。
- 汽水音乐网页端预渲染歌曲上限为 158 首。

## 🛠️ 从源码构建

```bash
pip install PyQt6 qtawesome requests pyinstaller imageio-ffmpeg
# 取 ffmpeg 放到项目根目录（打包用）
python -c "import imageio_ffmpeg,shutil; shutil.copy(imageio_ffmpeg.get_ffmpeg_exe(),'ffmpeg.exe')"

# 便携版（生成 dist/WoWeiGeKuang/）
pyinstaller -y --noconfirm --windowed --name WoWeiGeKuang ^
  --icon app_icon.ico --add-binary "ffmpeg.exe;." --collect-data qtawesome ^
  --hidden-import qtawesome main.py

# 安装版（需 NSIS）
makensis build/installer.nsi
```

## 📁 项目结构

```
main.py              # 主界面 / 线程 / 下载管理 / 历史记录
core_engine.py       # 搜索 / 歌单解析（网易云/酷狗/汽水） / 下载转码引擎
styles.py            # macOS 风格 QSS 样式
build/installer.nsi  # NSIS 安装脚本
```
